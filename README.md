# agent-skills

Practical skills for [Claude Code](https://claude.com/claude-code), packaged as
portable workflows that can be copied into any repository. The flagship skill,
[`five-a-side`](five-a-side/), is an adversarial review system designed to be
useful without turning every pull request into a long ceremony.

## [`five-a-side`](five-a-side/) — risk-budgeted adversarial review

The skill selects a small, repository-specific team from changed paths and
declared rule packs. It then budgets mutations, batches adjudication, and
limits remediation to one automated fix cycle.

| Lane | What happens |
| --- | --- |
| `exempt` | No model review; deterministic checks and normal human review remain |
| `standard` | Pack-selected reviewers, three mutation attempts, one adjudication batch |
| `critical` | Larger team/model allocation, six mutation attempts, two adjudication batches, and any declared human acknowledgement |

The plan is generated by `review_plan.py`, metrics are recorded by
`review_state.py`, and an optional CI gate is enforced by `review_gate.py`.
Because the same plan drives the interactive skill and CI, the risk policy is
not duplicated in several regexes.

The role slugs are stable and generic: `standards`, `spec`, `adversary`,
`operator`, `prover`, and `steward`. The optional Arsenal-inspired mode adds a
little matchday language—Starting XI, VAR check, halftime reset, final
whistle—without changing review policy or using club assets. See
[`five-a-side/references/arsenal-mode.md`](five-a-side/references/arsenal-mode.md).

## Design principles

- Gate on risk, not on every change.
- Make silence fail safe: a missing report is `INCOMPLETE`, never clear.
- Keep independent questions separate; one role cannot mask another.
- Use deterministic checks for deterministic work.
- Bound mutations, adjudication, and remediation so cost is predictable.
- Publish limits and measure false blocks, confirmed findings, and elapsed time.
- Keep packs short, cited, and owned by the repository that is being reviewed.

## Install

Each skill is a directory. Copy the one you want:

```bash
git clone https://github.com/adigunners/agent-skills.git
cp -R agent-skills/five-a-side <your-repo>/.claude/skills/five-a-side
mkdir -p <your-repo>/.claude/five-a-side/packs
```

Write packs for the domains in your own repository; the example and schema are
in [`five-a-side/references/pack-format.md`](five-a-side/references/pack-format.md).
The public snapshot contains only generic examples and placeholders. Do not
copy private incident details, credentials, internal URLs, or local paths into
a pack.
